# Разлом — браузерная RTS на HTML5

Классическая стратегия в реальном времени в духе Warcraft/StarCraft-lite, целиком
на **HTML5 Canvas + vanilla JavaScript (ES-модули)** — без движков, без сборки,
без зависимостей в рантайме.

## Как запустить

Нужен любой статический сервер (ES-модули не работают с `file://`):

```bash
python3 -m http.server 8000
# или: npx serve .
```

Открыть `http://localhost:8000`. Тесты:

```bash
node test/sim.mjs 12345 900 normal 1   # headless-симуляция (последняя 1 = ИИ против ИИ)
node test/browser.mjs                  # smoke-тест UI в jsdom
```

## Игра

- **Цель**: уничтожить все здания противника.
- **Экономика**: рабочие добывают золото (россыпи) и дерево (лес), относят в штаб.
- **Здания**: штаб (рабочие, сдача ресурсов), казарма (мечники/лучники),
  дом (+5 лимита снабжения), башня (авто-оборона).
- **Юниты**: рабочий, мечник (ближний бой, броня), лучник (дальний бой).
- **ИИ**: развивает экономику, строит дома/казармы/башни, обороняется и посылает
  волны атак нарастающей силы. Три уровня сложности (доход и размер волн).
- **Туман войны**, конечные ресурсы на карте, точка сбора у зданий.

### Управление

| Действие | Клавиши |
|---|---|
| Выбор / рамка / все юниты типа | ЛКМ / зажать ЛКМ / двойной ЛКМ |
| Приказ (идти, добывать, атаковать, достроить) | ПКМ |
| Атака-движение | `A` + ЛКМ |
| Стоп | `S` |
| К штабу | `H` |
| Постройки рабочим | `Q` штаб, `W` казарма, `E` дом, `R` башня |
| Обучение из казармы | `Q` мечник, `W` лучник |
| Группы | `Ctrl+1..5` создать, `1..5` вызвать |
| Камера | стрелки / край экрана / ЛКМ по миникарте, зум — колесо |
| Пауза | `Пробел` или кнопка |
| Точка сбора здания | ПКМ при выбранном здании |

## Архитектура

```
index.html          разметка + HUD
css/style.css       стили интерфейса
js/
  config.js         весь баланс: юниты, здания, сложность, константы
  utils.js          математика, seeded RNG, value-noise
  map.js            генерация карты (64×64): вода, лес, золото, коридор между базами;
                    пре-рендер террейна в offscreen-canvas
  pathfinding.js    A* по сетке со сглаживанием пути
  fog.js            туман войны (исследовано / видно / скрыто)
  entities.js       классы Unit / Building / Projectile
  game.js           симуляция: приказы, добыча, стройка, бой, производство, победа
  ai.js             контроллер ИИ (экономика, стройка, оборона, волны)
  camera.js         панорамирование, зум, преобразования координат
  input.js          мышь/клавиатура: выбор, приказы, размещение зданий, группы
  render.js         отрисовка мира: террейн, юниты, здания, снаряды, туман, призрак стройки
  ui.js             HUD: ресурсы, панель команд, выбор, миникарта, тосты, оверлеи
  main.js           bootstrap и игровой цикл (фиксированный шаг 60 Гц)
test/
  sim.mjs           headless-прогон боя (включая ИИ против ИИ)
  browser.mjs       smoke-тест DOM/canvas-интеракции в jsdom
```

Симуляция (`game.js` и ниже) не зависит от DOM — поэтому она гоняется в Node
для балансовых прогонов без браузера.

## Дорожная карта

**Итерация 1 — сделано:** ядро RTS (карта, пути, добыча, стройка, бой, туман войны),
ИИ с волнами и сложностями, полный HUD, миникарта, группы, автотесты.

**Итерация 2 — план:**
- звук и музыка (WebAudio, процедурные эффекты);
- новые юниты: конница (быстрая), осадная единица (против зданий);
- апгрейды в штабе (атака/броня);
- качество жизни: idle-worker счётчик, выбор всего войска по кнопке;
- индикаторы пути и полоса времени постройки на кнопках очереди.

**Итерация 3 — план:**
- сохранение/загрузка партии (сериализация состояния);
- сетевой хотсит (WebRTC) — симуляция уже детерминирована по seed и шагу;
- улучшенный ИИ: микроконтроль лучников, разведка, тайминг-атаки;
- балансировка по метрикам из `test/sim.mjs`.
