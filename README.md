# Красный радар — мобильная RTS на Kotlin (Android)

Мобильная стратегия в реальном времени **в духе Red Alert 2**: меню с красным
радаром и развёрткой, колонка кнопок справа, штурмы баз, шахтёры, танки,
турели и энергосистема. Игра, код и графика полностью оригинальные — проект
не содержит материалов EA и не аффилирован с EA; Command & Conquer и
Red Alert — товарные знаки их правообладателя, здесь они упомянуты
только как источник вдохновения.

## Меню

Главное меню повторяет композицию классического экрана: слева большая панель
с вращающейся развёрткой радара и метками, справа — колонка красных
глянцевых кнопок, сверху блок «ВНИМАНИЕ» со шкалой угрозы, снизу — версия.

Пункты меню (без сетевой игры, как и заказано):

- **Новая игра** → выбор сложности (Легко / Нормально / Сложно) → партия
- **Настройки** → сложность, звук вкл/выкл, сброс (сохраняются автоматически)
- **Авторы** → экран об авторах
- **Выход**

## Игра

- Карта 56×56: равнина, озёра, россыпи руды, гарантированный коридор между базами.
- Экономика: шахтёры возят руду в штаб. Кредиты — единый ресурс.
- Энергосистема: энергоблоки дают энергию, здания потребляют. Дефицит
  замедляет производство и турели — в духе классики жанра.
- Здания: штаб, энергоблок, казармы, военный завод, турель.
- Юниты: шахтёр, стрелок, ракетчик, танк.
- ИИ: развивает экономику, строит заводы и турели, обороняется и шлёт волны
  атак нарастающей силы; три уровня сложности.
- Победа: уничтожить все здания противника.

## Управление (тач)

| Действие | Жест |
|---|---|
| Выбор юнита/здания | тап |
| Приказ (идти, атаковать, добывать, точка сбора) | тап по цели при выделении |
| Камера | перетаскивание одним пальцем |
| Зум | щипок двумя пальцами |
| Все юниты типа | двойной тап |
| Переход к месту | тап по миникарте |
| Постройки/войска | кнопки СТРОИТЬ / ВОЙСКА внизу |
| Быстрый выбор | АРМИЯ, ШТАБ |
| Атака-движение | АТАКА, затем тап по точке |
| Пауза / выход в меню | кнопки ☰ и ⏸ сверху |

## Сборка

### Готовый APK

Собранный и подписанный APK лежит в репозитории: **`dist/RedRadar.apk`** (~870 КБ).
Установка: скопировать на телефон, открыть (разрешить «неизвестные источники»).
Требуется Android 7.0+ (minSdk 24). Подпись — самоподписанный сертификат сборки
(v1-схема; targetSdk 28, поэтому v2 не требуется).

### Обычная сборка (Android Studio)

Требуется Android Studio (Hedgehog или новее) или Gradle 8.7 + JDK 17:

```bash
# в Android Studio: File → Open → выбрать папку проекта → Run 'app'
# либо из командной строки (нужен Android SDK):
./gradlew assembleDebug
```

- minSdk 24 (Android 7.0), targetSdk 28
- Ориентация: альбомная (меню и игра нарисованы под неё)
- Внешних зависимостей нет — только `android.*` и Kotlin stdlib

### Сборка без Android SDK (в песочнице)

`tools/build_apk.sh` собирает APK вообще без Android SDK/Gradle — инструменты
берутся из разрешённых источников: JDK из PyPI (`jdk4py`), kotlinc из npm
(`kotlin-compiler`), `android.jar` (API 34) и `dx` из GitHub (blobs API).
Манифест компилируется собственным энкодером AXML (`tools/build_axml.py`),
APK собирается и подписывается на чистом Python (`tools/build_apk.py`,
v1-подпись через `cryptography`). Итог проверяется androguard.

```bash
pip install jdk4py cryptography
tools/build_apk.sh          # → dist/RedRadar.apk
```

## Структура

```
app/src/main/java/com/arena/redradar/
  MainActivity.kt        экраны: меню ↔ игра, настройки, звук, жизненный цикл
  menu/MenuView.kt       главное меню: радар с развёрткой, кнопки, настройки, авторы
  game/GameView.kt       SurfaceView-цикл: рендер, HUD, миникарта, тач-ввод
  game/Sim.kt            симуляция: юниты, здания, добыча, бой, производство, победа
  game/AI.kt             ИИ-противник: экономика, стройка, оборона, волны
  game/GameMap.kt        генерация карты, руда, сетка застройки
  game/Pathfinding.kt    A* по тайловой сетке со сглаживанием пути
  game/Sound.kt          системные сигналы (ToneGenerator, без файлов)
```

Симуляция (`Sim`, `AI`, `GameMap`, `Pathfinding`) не зависит от `android.*` —
её можно переносить и тестировать на JVM.

## Дорожная карта

- туман войны и миникарта с разведкой;
- encore-юниты: инженер, аптечки, ветеранство;
- сохранение партии (сериализация `Sim`);
- кампания с картами и сценариями;
- процедурная музыка/шумы вместо системных сигналов.
